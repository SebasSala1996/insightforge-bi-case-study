# InsightForge: BI Product Metrics Case Study

A full-stack Business Intelligence solution built to simulate a SaaS analytics platform. This case study features a realistic product metrics dashboard, driven by synthetic user behavior data, designed to inform strategic decisions across engagement, retention, and conversion.

---

## 🧠 Project Overview

This BI case replicates the challenges a **Senior BI/Product Data Engineer** might face at a SaaS or B2B tech company. From raw data generation to strategic dashboard delivery, this end-to-end solution showcases:

- Thoughtful metric design
- Advanced DAX & Power BI techniques
- Product-minded analytics
- Executive storytelling

The interactive Power BI dashboard answers **key product & business questions** based on realistic assumptions about user interaction with a digital product.

---

## 🎯 Business Questions Solved

### 1. **User Engagement**
- **Which features drive engagement?**  
  View total and average usage by feature with time-series trends.
- **How do free vs. paid users behave?**  
  Side-by-side comparisons reveal cohort-based feature interaction.
- **Do more interactions lead to upgrades?**  
  A correlation analysis shows increased usage aligns with conversion likelihood.

### 2. **Retention & Churn**
- **What’s our 1-week, 1-month, and 3-month retention?**  
  Visualized via dual line charts (relative & absolute).
- **Are specific features linked to churn?**  
  Filtering churned users shows no clear single-feature drop-off.

### 3. **Conversion Funnel**
- **Where do users drop off?**  
  A funnel + waterfall chart tracks user flow from first touch to conversion.
- **What engagement level predicts conversion?**  
  Users with >300 minutes of interaction show significantly higher upgrade probability.

### 4. **User Segmentation**
- Toggle between **New**, **Power**, and **Lapsed** users.
- Dynamic filtering updates all visuals to show segment-specific insights.

---

## 📊 Dashboard Features

- ✅ Conversion Funnel with Drop Analysis  
- ✅ Feature Usage Ranking & Cohort Comparison  
- ✅ Retention Curves (7, 30, 90 Days)  
- ✅ Correlation between Engagement and Upgrades  
- ✅ Segment-based Slicers (New, Power, Lapsed Users)  
- ✅ Custom DAX Measures (e.g. Conversion Probability)

> 📍 All visuals are fully interactive with dynamic bookmarks and filters.
